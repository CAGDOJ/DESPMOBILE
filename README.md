# SIVTR Ficha

Interface pública da ficha do motorista do SIVTR.

Este repositório contém somente HTML/CSS/JS e imagem institucional necessários para a ficha. O sistema principal, banco SQLite, painel administrativo, fotos operacionais e chaves administrativas permanecem no computador servidor do SIVTR.

Ative o GitHub Pages em **Settings → Pages → Deploy from a branch → main / root**.

URL esperada: `https://cagdoj.github.io/SIVTR-FICHA/`
